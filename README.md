## 🚀 Featured Project

### Flash Ticketing

> A production-deployed movie discovery, theater management, seat reservation, and ticketing platform designed to prevent overselling under heavy contention.

- Uses atomic Redis reservations with expiring holds and PostgreSQL as the durable source of truth.
- Confirms bookings idempotently so repeated payment callbacks cannot create duplicate orders.
- Streams live seat and queue updates over WebSockets and runs the backend in Docker.
- Supports customer, organizer, and administrator workflows in a single TypeScript monorepo.

**Stack:** `React` `TypeScript` `Node.js` `Express.js` `PostgreSQL` `Redis` `WebSockets` `Docker` `AWS`
